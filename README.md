🎯 Proje Amacı Kendi portfolyo sitemi sıfırdan inşa ederek hem backend hem de frontend tarafında pratik kazanmak, aynı zamanda gerçek bir proje deneyimi elde etmek.

🚀 Özellikler 🗂️ ASP.NET Core MVC mimarisi ile katmanlı yapı

🛢️ Entity Framework Core ile veritabanı işlemleri

✏️ CRUD operasyonları (Projeler, Hakkımda, İletişim vb.)

⚡ ViewComponent & PartialView ile modüler yapı

🎨 Bootstrap 5 ile responsive ve modern tasarım

🔍 LINQ sorguları ile veriye erişim

🗄️ Migration yönetimi ile veritabanı güncellemeleri

🛠️ Kullanılan Teknolojiler ASP.NET Core 6.0

Entity Framework Core

MS SQL Server

Bootstrap 5
